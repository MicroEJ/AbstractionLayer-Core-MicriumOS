# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-10-08

### Added

 - Add the cppcheck and Uncrustify configuration for the CI.

### Changed

 - Change license terms to MicroEJ Corp. BSD-style license.
 - Update build type.
 - Update the module structure to match the version 1.0.0 of the C module Template.
 - Update MISRA compliance to MISRA C:2012 with the cppcheck static analysis.
 - Update code formatting using Uncrustify.
 - Add the Architecture badge and a title to the README.

### Removed

 - Remove the `misra_2004_conf.h` header and the IAR MISRA C:2004 pragma macros.

### Fixed

 - Fix broken link in the README.

## [1.1.1] - 2021-06-15

### Changed

  - Fix project module name.

## [1.1.0] - 2021-06-14

### Added

  - MicroEJ time header.
  - LLMJVM Micrium OS MISRA-compliant implementation (MISRA C 2004).

## [1.0.0] - 2021-02-24

### Added

  - Initial revision.
